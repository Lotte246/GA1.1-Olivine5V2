add(a, b) function:
    This provides a function to add 2 numbers and prints the output. The funtion returns the mathematical sum if a combination of floats and integers in given as input. The function will break if a string is given as input with either a float or an integer. When two strings are given as input the function will concatenate the two strings despite this not being the intented purpose of the function. For example, add(a=1, b=2) will print '3', whereas add(a='Hello', b='World') will print 'HelloWorld'. In addition, calls like add(a=1, a='World') will result in an error.
